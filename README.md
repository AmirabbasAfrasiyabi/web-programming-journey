📌 Overview & Technologies Covered

This repository serves as a personal archive and showcase for my web development learning journey. It covers both client-side and server-side web development concepts:

Frontend: HTML5, CSS3 (Flexbox/Grid), JavaScript (DOM Manipulation, ES6+)

Backend: PHP (Form handling, session management, backend logic)

Database: MySQL / SQL (Database structure, CRUD operations, PDO/MySQLi connections)

🚀 How to Use & Git Workflow

1. Clone the Repository

Open your terminal or command prompt and run:

# Navigate to your local server directory (e.g., C:/xampp/htdocs/)
cd path/to/your/projects

# Clone the repository
git clone https://github.com/YOUR_USERNAME/web-development-course.git

# Enter the project folder
cd web-development-course


2. Basic Git Commands (For Saving Progress)

# Check status of modified files
git status

# Stage all updated files
git add .

# Commit changes with a message
git commit -m "Add PHP database connection exercise"

# Push changes to GitHub
git push origin main


⚙️ Running PHP & Database Files Locally

Install and launch XAMPP (or WAMP/Laragon).

Start the Apache and MySQL modules.

Place this repository inside the local root directory (e.g., htdocs).

Access database interface via http://localhost/phpmyadmin/ to manage databases.

Open your browser and navigate to http://localhost/web-development-course/.
