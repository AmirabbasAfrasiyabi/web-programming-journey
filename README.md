# 🌐 Web Programming Course

This repository contains my code exercises, assignments, and projects completed during the [Web Programming Course on Maktabkhooneh][course].

## 📌 Overview & Technologies Covered

This repository serves as a personal archive and showcase for my web development learning journey. It covers both client-side and server-side web development concepts:

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (DOM Manipulation, ES6+)
* **Backend:** PHP (Form handling, session management, backend logic)
* **Database:** MySQL / SQL (Database structure, CRUD operations, PDO/MySQLi connections)

## 📂 Repository Structure

```
.
├── 01-html-fundamentals/    # HTML semantic layouts and form exercises
├── 02-css-design/           # Responsive designs, Flexbox, and Grid layouts
├── 03-javascript-basics/    # JS logic, DOM manipulation, interactive scripts
├── 04-php-backend/          # Server-side scripts, sessions, and logic
├── 05-databases/            # SQL schemas, queries, and DB connection scripts
├── 06-projects/             # Full-stack dynamic web projects
└── README.md                # Documentation
```

## 🚀 How to Use & Git Workflow

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
# Navigate to your local server directory (e.g., C:/xampp/htdocs/)
cd path/to/your/projects

# Clone the repository
git clone https://github.com/AmirabbasAfrasiyabi/web-development-course.git

# Enter the project folder
cd web-development-course
```

### 2. Basic Git Commands (For Saving Progress)

```bash
# Check status of modified files
git status

# Stage all updated files
git add .

# Commit changes with a message
git commit -m "Add PHP database connection exercise"

# Push changes to GitHub
git push origin main
```

## ⚙️ Running PHP & Database Files Locally

1. Install and launch XAMPP (or WAMP/Laragon).
2. Start the Apache and MySQL modules.
3. Place this repository inside the local root directory (e.g., `htdocs`).
4. Access [`http://localhost/phpmyadmin`](http://localhost/phpmyadmin) to manage databases.
5. Open your browser and navigate to [`http://localhost/web-development-course/`](http://localhost/web-development-course/).
